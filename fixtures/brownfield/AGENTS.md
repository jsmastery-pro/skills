# AGENTS.md

## Stack

- Node 20, plain JavaScript, no framework.
- Sessions in an http only cookie.

## Commands

- Test: `npm test`
- Start: `npm start` (http://localhost:3000, `PORT` overrides)
- Dev account: `demo@example.com` / `demo-password` (seeded in `src/auth/users.js`)

## Conventions

- Two space indents, single quotes.
